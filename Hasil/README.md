# Folder Hasil & Analisis

Direktori ini dialokasikan untuk menyimpan luaran analisis, visualisasi grafik, dan tabel rekapitulasi performa eksperimen E0 s.d. E4.

## Konten yang Diharapkan:
- Kurva konvergensi training & validation loss.
- Confusion matrix komparasi Task 1 (SSH-Patator) vs Task 2 (DoS).
- Tabel rekapitulasi Macro-F1, per-class Recall, dan Backward Transfer ($BWT = R_{2,1} - R_{1,1}$) dalam format $Mean \pm Std$ (5 seed).
- Grafik perbandingan retensi forgetting: E1 vs E2 (efek EWC lokal) dan E3 vs E4 (efek EWC pada FL).
