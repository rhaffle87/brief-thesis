# Direktori Bimbingan

Direktori ini memuat seluruh materi persiapan presentasi bimbingan, panduan tanya jawab pertahanan argumen (*defense*), serta rekam historis arahan dosen.

## Dokumen Utama:

- **[Bahan-Paparan-Pembimbing.md](Bahan-Paparan-Pembimbing.md)** - Struktur slide presentasi eksekutif siap pakai untuk memaparkan perkembangan metodologi dan data kepada pembimbing.
- **[Panduan-Tanya-Jawab-Pembimbing.md](Panduan-Tanya-Jawab-Pembimbing.md)** - Bank argumen defensif ilmiah dan jawaban antisipatif terhadap pertanyaan kritis dosen seputar non-IID, class imbalance, dan penghapusan fitur port.
- **[Pembahasan-Menyeluruh-Bimbingan-Lanjutan.md](Pembahasan-Menyeluruh-Bimbingan-Lanjutan.md)** - Dokumen komprehensif kajian literature review CL (EWC, SI, MAS, LwF, GEM) dan FL (FedAvg, FedProx, SCAFFOLD, FedCurv), bedah analogi pagar ITS 180 hektar, skala node edge, opsi metode komplementer, dan pemetaan dataset luar domain IDS.
- **[Verifikasi-Literatur-dan-Keputusan-Metode-Klien.md](Verifikasi-Literatur-dan-Keputusan-Metode-Klien.md)** - Dokumen verifikasi independen literatur, status validitas referensi FCL, serta justifikasi rezim cross-silo FL.
