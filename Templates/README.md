# 📝 Direktori Templates

Direktori ini memuat template terstandar untuk pencatatan dalam Obsidian Vault guna menjaga konsistensi format penulisan dan metadata.

## 📂 Berkas Template:

- **[Template-Literatur.md](Template-Literatur.md)** — Kerangka baku telaah naskah paper ilmiah (metadata, 3 temuan kunci, relevansi RM, dan sitasi).
- **[Template-Log-Eksperimen.md](Template-Log-Eksperimen.md)** — Kerangka baku pencatatan hasil eksekusi eksperimen per seed (hyperparameter, metrik evaluasi F1/Recall/BWT, dan durasi).
