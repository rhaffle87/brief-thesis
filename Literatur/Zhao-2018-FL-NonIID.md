# Federated Learning with Non-IID Data (Zhao et al., 2018)

- **Penulis:** Yue Zhao, Meng Li, Liangzhen Lai, Naveen Suda, Damon Civin, Vikas Chandra
- **Institusi:** Arm Inc.
- **Tahun:** 2018
- **Publikasi:** arXiv:1806.00582 [cs.LG]
- **Status Berkas:** Tersedia di `Literatur/PDFs/Opsional/Zhao-2018-FL-NonIID.pdf`
- **Relevansi Penelitian:** Memberikan analisis teoretis dan empiris pertama mengenai penurunan performa FedAvg ketika berhadapan dengan data non-IID (earth mover's distance / EMD antara distribusi data klien dan populasi), serta memperkenalkan konsep data-sharing strategy dan pengaruh variasi lokal pada bobot global.
